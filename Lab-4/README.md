# Lab 4 — Centipede Vibe Coding

Based on SETAPESU26/27_centipede. Requires Python 3.10+ and pygame.

## Run

```cmd
py -m pip install -r requirements.txt
py game.py
```

Arrow keys move, Space shoots, R resets. The game now requires four mushroom hits, displays a white flash on mushroom damage, shows sparks when a segment is destroyed, and speeds up later waves.
